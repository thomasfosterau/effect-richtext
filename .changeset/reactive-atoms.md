`/Reactive` adds `editorStateAtom(source)` and `selectAtom(source, f, eq?)`: read-only `effect/reactivity` atoms over a `StateRef` or `EditorObserver`, for UIs that render from atoms. Effect still marks the `Atom` API as unstable, so these may change with an Effect minor release.
